
# SIEM Log Analysis — Wazuh

## Project Overview

Conducted a security incident investigation in a simulated corporate environment using Wazuh SIEM.

The investigation focused on suspicious activity affecting a Linux web server and a Windows Domain Controller.

## Tools and Technologies

- Wazuh SIEM
- Windows Event Logs
- Linux and Web Server Logs
- PowerShell
- MITRE ATT&CK Framework

## Key Findings

### Linux Web Server
- Identified reconnaissance and directory enumeration.
- Investigated SQL Injection attempts.
- Detected successful Shellshock exploitation and remote command execution.

### Windows Domain Controller
- Analyzed suspicious PowerShell activity.
- Identified downloads of Mimikatz-related tools.
- Investigated GodPotato privilege escalation activity.
- Examined suspicious Windows service creation.

## Investigation Activities

- Analyzed high-severity security alerts.
- Correlated security events across Windows and Linux.
- Reconstructed the attack timeline.
- Identified Indicators of Compromise (IOCs).
- Mapped findings to MITRE ATT&CK techniques.
- Documented security findings and remediation recommendations.
