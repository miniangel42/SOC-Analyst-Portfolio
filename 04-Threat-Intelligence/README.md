
# Threat Intelligence — Bloody Wolf

## Project Overview

Conducted a threat intelligence investigation into the Bloody Wolf (also known as Stan Ghouls) cyber threat group and its NetSupport RAT campaign targeting organizations in Central Asia.

The objective was to analyze the attacker's techniques, malware delivery mechanisms, persistence methods, command-and-control infrastructure, and indicators of compromise.

## Tools and Frameworks

- Open-Source Threat Intelligence (OSINT)
- MITRE ATT&CK Framework
- VirusTotal
- Malware Hash Analysis
- IOC Analysis
- Threat Intelligence Reporting

## Key Findings

### 1. Threat Actor Attribution
- Investigated the Bloody Wolf (Stan Ghouls) threat group.
- Examined phishing campaigns targeting organizations in Uzbekistan and neighboring countries.
- Correlated campaign characteristics with publicly available threat intelligence.

### 2. Phishing and Initial Access
- Analyzed spear-phishing activity involving fake legal documents.
- Investigated social engineering techniques involving fraudulent Java installation requirements.
- Documented malware delivery through deceptive download links.

### 3. NetSupport RAT Analysis
- Studied the NetSupport RAT deployment process.
- Documented the loader execution flow and associated malicious components.
- Analyzed the malware's remote-access capabilities.

### 4. Persistence Mechanisms
Identified three persistence techniques described in the campaign:

- Windows Startup Folder
- Windows Registry Run Keys
- Windows Scheduled Tasks

Mapped these techniques to MITRE ATT&CK.

### 5. Command and Control
- Investigated attacker-controlled domains and C2 infrastructure.
- Documented indicators associated with malicious network communications.
- Examined reported infrastructure overlap with Mirai IoT malware.

### 6. Indicators of Compromise
Collected and documented:

- Suspicious domains
- Malware file hashes
- Malicious filenames
- Registry indicators
- Scheduled task artifacts

## Investigation Methodology

1. Reviewed available threat intelligence reports.
2. Investigated phishing techniques and malware delivery.
3. Analyzed the documented NetSupport RAT execution chain.
4. Identified persistence mechanisms and C2 indicators.
5. Mapped attacker behavior to MITRE ATT&CK.
6. Consolidated findings into a threat intelligence report.
